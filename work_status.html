Status control

Questa pagina per ora aggiorna solo lo stato locale. Dopo colleghiamo i pulsanti a un backend (es. Firebase) e l'indicatore fisico leggerà lo stato via ESP8266.

Notes

Pipeline prevista:

  • Questa UI scrive lo stato work_status in un backend (es. chiave indicator/status).
  • L’ESP8266 fa polling via HTTP GET e aggiorna i LED in base allo stato letto.
  • I sensori di presenza vengono ignorati: lo stato è deciso solo dal web.

Firmware hook

Lato firmware avrai un enum tipo IndicatorState e una funzione updateLedsFromState() che traduce lo stato nel pattern di luce.
